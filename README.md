## English

A camera web app made with **pure HTML** — the whole camera is just **53.9 KB (55,234 bytes)**, no frameworks, no dependencies, no build tools.

**Features:**

- 📷 **Photo** — capture in JPG / PNG / WebP
- 🎥 **Video** — record in MP4 / WebM
- 🎛️ **Manual Pro Controls**
  - ISO (sensitivity) — Auto or manual
  - Shutter speed — Auto or manual
  - Exposure compensation
  - White balance — Auto or manual
- 🔍 **Zoom** — up to 1.0x+ optical/digital zoom
- 📱 **Multi-camera** — switch between main / front / other lenses
- 🖥️ **Resolution** — from 720P 30fps all the way to **4K 60fps**

Suitable for quick shots, testing device cameras, and casual non-professional photography.
